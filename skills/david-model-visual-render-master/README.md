# AIGC DAVID · 产品模型视觉渲染大师 2.1

以**用户真实 3D 模型为产品身份源**，参考图仅提供 **CMF、摄影灯光、构图、背景、版式**。本 Skill 针对 2.0 试运行中的错误进行了修订：模型是常规 TKL 键盘，却错误生成了参考照片里的带旋钮/竖屏键盘。2.1 增设“原模型几何证据”强制检查关卡。

## 一句话使用

上传原始模型（推荐 GLB，也可 FBX/OBJ/BLEND/STL）和参考图，发送：

> 用产品模型视觉渲染大师 2.1。我的模型是唯一产品结构依据，参考图只用于 CMF、灯光和构图。先生成并核对模型真实结构视图，然后用商业海报模式输出高品质效果图；禁止复刻参考图里的产品结构。

## 四个模式

- A · 商业主视觉（默认）
- B · 六视角展示
- C · CMF 探索
- D · 参考海报复现

## 图像一致性等级

- **G：真实原网格渲染**，原产品网格为画面数据来源，可做几何校验。
- **V：基于原模型视图的 AI 视觉重绘**，以原模型预览为条件，结构保真但不保证网格级 100% 一致。
- **U：模型未核实**，不能宣称是基于原模型生成的成品。

格式可接收不等于当前会话一定能解析：尤其 FBX/BLEND 等格式，需有可用的三维处理工具或可靠转换路径。**不能读模型时不能直接对着参考图里的产品出图。**
