# 可复制使用的口令

## 1｜商业海报（默认）
用产品模型视觉渲染大师 2.1。模型文件是**我的产品**，参考图只提供 CMF、光影、构图、背景。先实际读取模型并输出结构视图确认产品身份，再基于此输出 1 张高级商业主视觉。不得把参考图片中的另一款产品做进成品。

## 2｜六视角
用产品模型视觉渲染大师 2.1 的六视角模式。严格依据上传的真实 3D 模型，输出正、左、右、后、顶、底六张视图，保持同一模型、同一 CMF，不能推断或添加接口、按键。若没有真实网格渲染能力，明确标注为 AI 概念视图。

## 3｜CMF 对比
用产品模型视觉渲染大师 2.1 的 CMF 模式。产品造型与功能结构只采用上传模型。以固定机位输出 3 种材质组合：深灰喷砂铝 + 哑黑、暖白磨砂 + 浅灰、枪灰金属 + 深蓝。只修改颜色/粗糙度/反射/灯光，不动零件位置。

## 4｜海报复现
用产品模型视觉渲染大师 2.1 的参考海报复现模式。前面的海报图仅参考版式和摄影光影，真实产品只来自后面上传的模型。严格禁止照搬海报中的产品结构，必要时牺牲部分构图相似度来保证我的模型身份。

## 5｜失败纠错
这张不对，它像参考图的产品而不是我的 3D 模型。停止参考图主导的生成；重新读取我上传的模型，输出中性材质结构预览供核对，然后只将参考的 CMF、灯光、构图迁移到真实产品上。
