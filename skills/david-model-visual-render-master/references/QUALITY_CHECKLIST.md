# 产品模型视觉渲染质量检查表（2.1）

## P0：结构证据检查（未通过就不能出正式稿）

- [ ] 真实上传的模型文件已被读取，或用户模型截图已被明确验证。
- [ ] 已输出/核对真实模型结构视图，**不是**根据参考图 AI 重绘的伪模型图。
- [ ] 记录选中的模型对象/设计变体，未把 FBX 内多个版本叠在一起。
- [ ] 参考图没有被误当成模型截图或造型依据。

## P1：原产品一致性（未通过则判失败）

- [ ] 外轮廓、机身长宽厚比例未显著偏移。
- [ ] 功能区总数量和分布不变，未凭空出现旋钮、屏幕、按键、开孔。
- [ ] 已知接口位置及部件连接关系与原产品一致。
- [ ] 正常键帽字符/产品标志如不可准确保留，明确标示而非假造。
- [ ] 不曾从参考图“偷渡”产品身份、物理结构或功能组件。

## P2：CMF 和摄影

- [ ] 材质映射到**已有**零件，例如外壳喷砂铝、键帽哑黑、控制面板磨砂材质。
- [ ] 主辅光源与轮廓光关系和参考风格一致。
- [ ] 背景、留白、摄影角度与排版贴近参考，同时允许为展示原产品适度调整。
- [ ] 真实光泽粗糙度、反射、接触阴影，避免塑料质感冒充金属。

## P3：交付与诚实说明

- [ ] 交付实际图片，而非仅有提示词。
- [ ] G/V/U 来源及结构保真级别明确。
- [ ] 用户模型未被公开上传到仓库，除非用户单独授权。
- [ ] 如果无法保真，明确列出局限；不写“完全无损”“100%几何一致”等无证据保证。

## 典型反例

模型是普通 TKL 键盘，参考图片是一台带 2 旋钮 + 竖屏 + 4 控制键的键盘。生成结果仍出现这些参考部件 = **严重失败**。正确结果必须采用 TKL 真实键盘，CMF 仅采用参考中的深灰金属、黑色键帽、暗调摄影、柔光和构图气质。
