# 产品参考海报复现

以参考决定画面，以六视图决定产品。每张参考单独实际生成一张对应成图，不只输出分析或提示词。使用中文简洁沟通。

版本：1.0.0。整理：AIGC DAVID。允许分享和修改本工作流；不附带用户图片、第三方海报、品牌资产或模型权限。署名不代表默认给成图加水印。

## 1. 解析本轮图片

仅计入用户指定的本轮图片集合；排除Skill、PDF等附件，不计历史图片、工具生成结果或预览。按明确上传顺序编号，默认N≥7，海报参考数量M=N−6：

| 本轮序号 | 身份 |
| --- | --- |
| 1…N−6 | R01…RM，海报参考 |
| N−5 | V-F，正视图／正面 |
| N−4 | V-L，正左侧视图 |
| N−3 | V-R，正右侧视图 |
| N−2 | V-B，后视图／背面 |
| N−1 | V-T，顶视图 |
| N | V-D，底视图 |

例如N=10，前4张参考对应4张成图，后6张为产品视图；不默认出3张或6张。用户明确标注的身份和次序优先；无标注时按上表，不凭外观静默换序。

先实际查看全部参考和六视图，建立真实文件名／附件ID映射。只有文字描述或文件名时不声称已看图。路径失效时检查本轮指定路径与附件清单；找不到则请求补传缺失项。不要读取无关历史图片猜测。

以下情形集中提出必要澄清：顺序无法确定、N不足7、六视图缺失或重复、标签与次序冲突、六图不是同一产品。跨多条消息上传时按用户明确的集合合并，不把全对话累加。仅阻塞依赖缺失证据的步骤，可继续分析已读参考；不能编造缺图。只有一张六视图拼图或透视图时说明与约定的差别，可按明确标签读取，不称为六张真实正交原图。

简述“识别M张参考＋6张产品视图，将输出M张独立图”。除关键歧义外连续完成，不逐张重复问确认。

## 2. 锁定产品身份

用[工作模板](#work-templates)建立产品锁定表：P01…必须保留项，U01…未知或矛盾项，每项注明证据视图／用户要求。

检查主体轮廓、宽高深关系、体块组成、圆角切面、分件线；各面屏幕、镜头、灯、按键、接口、孔阵和标识的数量、形状、朝向、相对位置；顶底背面组件、支撑与左右非对称特征；配色、材质观感、光泽及纹理方向。

明确产品自身左／右与画面左／右的区别，以V-F为前方交叉核验其他面；不得镜像接口或把右侧特征复制到左侧。不同裁剪图的像素大小不能直接当实物尺寸；按共同部件及相对关系判断比例。

仅描述可见证据，不把开孔自动当麦克风、球头当天线、缝隙当可拆结构。六视图不足以证实的曲面过渡、隐藏细节、精确尺寸及内部结构标为未知；冲突要澄清，不取平均或用参考海报填成事实。

更换产品时重建锁定表，不继承示例音箱的四键、球头、暖白色、CUBI名字或旧水印。

## 3. 逐张拆解参考，不混合风格

为每张R_i单独记录：原始宽高比；主体数量、占比、中心、边界和留白；镜头方位高度、透视、倾斜、悬浮／落地、遮挡；文字、卡片、道具、背景结构的版位与层叠关系；字体气质、字号层级、字重、行距、对齐、色彩；光向软硬、阴影、反射、景深、颗粒及整体审美。

将重要元素用0–1归一化边界框[x,y,w,h]描述，估读数值标“约”。先数清卡片数和行列组合，禁止把17卡简化为8卡。无文字参考保持无文字，不默认加Logo、标题、型号、水印或网址。

各图沿用对应参考的比例，不统一强制3:4。工具只能输出近似比例时记录差异，不挤压产品或声称像素级还原。模板见[工作模板](#work-templates)。

## 4. 适配画面而不重设计产品

默认锁定产品造型、CMF、标识和可见部件，只改变视角、光照、场景、构图与排版。参考产品只提供摆位与体量参照，不提供本产品结构或材质。光照能改变反射明暗，不能把暖白壳体改绿、把不透明壳体变成发光灯。

冲突优先级：用户明确要求→产品真实性→参考构图排版→装饰。不同品类比例有差异时保持自然比例，用缩放、视角、合理裁切适配；不把方形音箱拉长成水瓶，不为了瘦长剪影删部件。必要适配简短说明，不谎称完全相同。

- 多整机参考：用同一产品多个实例或有证据支持的不同视角，保留数量与节奏，不默认新配色或家族产品。
- 巨型特写：用本产品可见特征替换；裁切与遮挡不能当作部件删除。不得无意遮住需要呈现的关键识别特征。
- 道具、透明色片、悬挂件与光迹是场景，不把它们画成拆件／附件或性能演示；必要时调整连接关系避免误读。
- 爆炸图、剖面、芯片、电池卡片：六视图没有内部证据则保留版位与明暗节奏，改用真实外观细节，不编内部硬件和装配。
- 参考的商标、型号、口号、网址、参数、版权不得照搬。保留文字层级与占位，用用户提供品牌／文案替换；没有名称时用准确产品类别，不擅自命名型号、编网址或加注册符号。仅用户要求起名时拟名并注明命名方案。
- 信息框只写用户提供的参数或可见准确计数。未知性能改为有依据的定性内容，保留排版；不得挪用参考的续航、功率、防水、销量、尺寸或认证。
- 重要文字、Logo和严格网格必要时用适用版式工具精排。准确Logo尽量采用用户提供资产，不把近似生成字形称为准确原标识。

## 5. 实际逐张出图

检查当前可用图片查看、生成／编辑及文件能力，使用适用imagegen技能并遵守工具传图规范；不声称调用未接入模型。每张成图O_i对应R_i，独立生成一次，默认最终图总数M；不拼合集交差，不用重复构图凑数。仅用户明确只要提示词时才不出图。

按[生成与修复模板](#prompt-templates)构造每次请求：

1. 只有当前R_i决定风格，明确标注所有输入图片的角色。
2. 每次实际传入同一组六视图的可访问图像证据及产品锁定项，不仅写“参照之前的产品”，不依赖上一张生成结果猜造型。
3. 容量允许时传R_i＋全部6张视图。容量不足时用真实六视图制作清晰带标签证据拼图，并传目标可见面的原分辨率图；保持长宽比，不镜像、不转错朝向、不裁掉接口。拼图只是输入证据，不是成图。清晰度仍不够时说明限制，调整支持的传入方式，不静默丢关键证据。
4. 修复另带待修图，仍保留原参考和相关产品证据。独立任务可并发，记录和展示按R01…RM顺序对应；不得混入其他R的风格。

工具返回后实际查看输出。不能生成或不能读取时标明失败／待检查，保留已完成项，不用提示词冒充图片，不声称全数交付。

## 6. 双重检查与局部修复

每张同时对照R_i、六视图及锁定表，不能只判断整体像不像。

- 产品：轮廓比例、面向与左右关系、部件数量和相对位置、颜色材质、孔阵、原标识；逐个数按钮、接口，包括特写与重复实例。区分透视／遮挡和真实变形。
- 版式：比例、主体数／占比／位置、留白、卡片数／边界、裁切遮挡、标题层级／对齐、道具、光向色调。
- 文案：有无乱码、参考商标残留、未经要求添加的字、错误参数或虚构功能。

只用“符合／存在偏差／无法判断”并提供具体可见证据，不用“高级”“基本一致”替代检查，不打无依据100%分数。

发现关键偏差先针对性修复，仅改错误区域，再检查是否引起连带变化。按键真实4枚而特写画成5枚时，修复后实际重数，不能因提示词写4就认定成功。最多连续两轮修复同一问题；仍失败则停止重复生成，标清待修并提出可用的精确合成／局部编辑方案，不悄悄改锁定表让它通过。

文字或网格反复不稳时用适用版式工具精排，产品背景仍实际生成；用户要可编辑文件时保留真实文字和图层，不以整页位图冒充。未验证项不能包装为工程定稿。

## 7. 交付与后续复用

按参考顺序展示M张独立结果，简短标“图i｜对应参考i”，保留可访问结果；工具已显示时不无意义重复显示。简报实际完成数及必要偏差，不默认倾倒长分析或全部提示词。只称已完成实际生成且可访问的项。

在当前上下文或项目文件维护：输入映射、六视图版本、产品锁定表、各R布局图、各O版本、检查状态与待修项，模板见[工作模板](#work-templates)。不承诺跨对话永久记忆附件；跨对话使用移交摘要与当前文件恢复，缺基准就说明。

追加参考但沿用同组六视图时复用已核验基准；用户更新视图则记录版本、复查受影响成图，不用旧图冒充新版。更换产品只复用流程，不继承旧产品特征。

本Skill依赖宿主实际能力，不自动授予生图权限，不保证精确三维重建、隐藏内部结构或无误的像素复刻。

## 快速调用

“用产品参考海报复现。共10张：前4张海报参考，最后6张依次正面、正左侧、正右侧、背面、顶部、底部。分别出4张图，保持产品造型配色与部件一致。”

边界示例见[使用示例](#examples)。

## 附录2：生成与修复模板

## 生成与修复模板

用本项目真实信息替换占位项，不带入旧产品细节。

### 单张生成

```text
实际生成一张完整商业视觉图，与R_i一一对应。
输入身份：图1为当前海报参考，只决定构图排版与审美。
图2…7是产品正面、正左侧、正右侧、背面、顶部、底部，是产品权威证据。
如用六视图证据拼图，改写为实际编号和标签，注明另附的原分辨率可见面。
画布：[当前参考比例]。
布局：[真实归一化坐标、主体数量、占比、留白、视角、裁切、遮挡、层叠、卡片]。
摄影：[本张参考的背景、光向、软硬、色调、反射、阴影、景深]。
产品锁定：[P01…所有关键项、面向左右、数量位置、CMF]。
视角依据：[对应六视图]。
道具：[只作独立场景，不代表产品拆件或功能]。
文字：[真实品牌／准确文案；无文字参考不加字]。
参数：[已知数值；未知部分的定性替换]。
适配：[保持产品自然比例，不为参考剪影变形]。
禁止混入参考产品的造型、材质、商标、性能和隐藏结构。
只完成本张独立图，不拼其他参考，不混合其风格。
```

### 按构图补充

- 卡片图：逐卡列位置、背景明暗、图片、字重、对齐，明确总数，不简化。
- 巨型特写：记画外裁切和完整小整机的坐标，重复部件在不同尺度保持一致。
- 多整机：逐个列边界、朝向、前后关系，明确同一配色同一产品。
- 色片／悬挂／网格：列道具连接关系，避免当作拆件或真实性能展示。

### 局部修复

```text
输入：待修O_i-Vxx、原R_i、相关真实六视图／证据图。
只修改[具体区域、错误部件或文字]。
依据：[Pxx及可见证据]。
目标：[明确数量、位置、准确文字，必要时附归一化区域]。
保留：[其他已确认造型、布局、字、背景、相机、材质与光影]。
避免：[此次可能发生的连带变化]。
这是修复而非重设计；完成后实际查看、重数，并检查其他关键项。
```

同一问题连续两轮未修复，停止重复尝试，标明待修并采用可用精确合成等方案，不把提示词的期望当结果。

## 附录3：使用示例

## 使用示例与边界

### 多参考
11张本轮图片：前5张参考，后6张为同一咖啡机六视图。输出5张分别对应的图，不继承CUBI四键／球头特征。

### 两张不同风格
8张图片：前2张分别黑底特写和米色家居，后6张为耳机盒视图。出2张独立图，每次用同组六视图；黑底蓝光不能污染暖色家居。

### 顺序冲突
用户说按默认顺序，但N−4图标BOTTOM。指出编号冲突并澄清，可先分析海报，不静默把底图认作右侧。

### 假参数风险
参考有16小时续航、IPX7和电芯爆炸图；用户没给参数或内部结构。保留卡片数量、位置和明暗，用外观细节和真实计数替换，不编性能。

### 品类比例冲突
瘦长水瓶参考＋横向音箱六视图：保留主体中心、背景、镜头和前景，用真实音箱比例适配，不拉长机身；简述必要适配。

### 仅六图
只有6张产品视图，M=0。先建立产品锁定项，请用户补至少1张参考或明确另行创作；不扣其中1张为参考导致缺底图。

### 多批上传
用户明确两批合并为本轮12张，前6张参考后6张视图：用该集合，不计更早附件或工具图片。宿主不能确认顺序时先核对角色，不按文件名时间猜顺序。

### 左右与计数
右视图双接口、左视图无接口、正面3键；成图镜像接口且特写4键。依据原视图局部修复，实际查看并重数，不因提示词正确标通过。

### 无可用生图工具
保留已读取的输入映射与可执行提示词，明确尚未出图，不称“已生成M张”，不让用户误以为粘贴Skill即获得工具权限。
