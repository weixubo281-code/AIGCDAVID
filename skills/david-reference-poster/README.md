# 产品参考海报复现 · AIGC DAVID

根据多张海报参考与同一产品六视图，逐张制作保持产品一致的商业视觉。

**几张参考，就分别出几张图。参考决定画面，六视图决定产品。**

## 快速使用

1. 上传本目录的[单文件 MD 版](产品参考海报复现_单文件版.md)，让助手读取规则；支持标准 Skill 的环境可使用本目录的 [SKILL.md](SKILL.md) 与配套文件。
2. 按顺序上传图片：前 N−6 张是海报参考，最后六张依次为正视图、正左侧视图、正右侧视图、后视图、顶视图、底视图。
3. 发送调用指令：

> 用产品参考海报复现。共10张图：前4张海报参考，最后6张依次正面、正左侧、正右侧、背面、顶部、底部。分别出4张独立图，保持产品造型、配色与部件一致。

例如上传12张图片，前6张参考＋后6张视图，最终对应6张独立成图。图片跨多次上传时，明确本轮集合和顺序。

## 工作流程

识别输入 → 锁定六视图特征 → 逐张拆解构图排版 → 分别实际生成 → 核对产品与版式 → 局部修复 → 对应交付。

- 保留每张参考的画幅、主体位置、留白、层级、卡片与光影，不混合所有参考风格。
- 保留真实产品的轮廓、材质、配色、按键与接口数量及左右关系。
- 无文字参考保持无文字；有文字时采用已提供的品牌和准确文案。
- 不挪用参考产品的续航、防水或功率等参数；内部结构无证据时改用外观细节。
- 更换产品时重新读取六视图，不继承上一产品特征。
