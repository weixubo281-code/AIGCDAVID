# 生成与修复模板

用本项目真实信息替换占位项，不带入旧产品细节。

## 单张生成

```text
实际生成一张完整商业视觉图，与R_i一一对应。
输入身份：图1为当前海报参考，只决定构图排版与审美。
图2…7是产品正面、正左侧、正右侧、背面、顶部、底部，是产品权威证据。
如用六视图证据拼图，改写为实际编号和标签，注明另附的原分辨率可见面。
画布：[当前参考比例]。
布局：[真实归一化坐标、主体数量、占比、留白、视角、裁切、遮挡、层叠、卡片]。
摄影：[本张参考的背景、光向、软硬、色调、反射、阴影、景深]。
产品锁定：[P01…所有关键项、面向左右、数量位置、CMF]。
视角依据：[对应六视图]。
道具：[只作独立场景，不代表产品拆件或功能]。
文案版本：[本项目C-Vxx；固定产品名、英文拼写与概念型号]。
文字：[逐字列出本图实际文案及对应版位、层级、行数；取自统一文案表；无文字参考不加字]。
参数：[已知数值；未知部分的定性替换]。
适配：[保持产品自然比例，不为参考剪影变形]。
禁止混入参考产品的造型、材质、商标、性能和隐藏结构。
不得把海报上的新名字擅自印到产品机身，不改原有清晰标识；不把概念型号描述为真实硬件规格。
只完成本张独立图，不拼其他参考，不混合其风格。
```

## 按构图补充

- 卡片图：逐卡列位置、背景明暗、图片、字重、对齐，明确总数，不简化。
- 巨型特写：记画外裁切和完整小整机的坐标，重复部件在不同尺度保持一致。
- 多整机：逐个列边界、朝向、前后关系，明确同一配色同一产品。
- 色片／悬挂／网格：列道具连接关系，避免当作拆件或真实性能展示。

## 局部修复

```text
输入：待修O_i-Vxx、原R_i、相关真实六视图／证据图、当前C-Vxx逐字文案。
只修改[具体区域、错误部件或文字]。
依据：[Pxx及可见证据]。
目标：[明确数量、位置、准确文字，必要时附归一化区域]。
保留：[其他已确认造型、布局、字、背景、相机、材质与光影]。
避免：[此次可能发生的连带变化]。
这是修复而非重设计；完成后实际查看、重数，并检查其他关键项。
```

同一问题连续两轮未修复，停止重复尝试，标明待修并采用可用精确合成等方案，不把提示词的期望当结果。
