# 统一命名与文案

先建立一套信息，再按不同参考的版位裁取使用；不在每张海报临时重起名字。

## 信息来源与允许表达

| 信息 | 采用方式 | 边界 |
| --- | --- | --- |
| 用户已有品牌、名称、型号 | 逐字沿用 | 不拿参考品牌替换，不随意翻译真实专名 |
| 新中文产品名 | 依据类别和可见设计气质拟定，优先简短易读 | 不因名字引入未证实功能；不宣称完成商标检索 |
| 英文名 | 需要英文版位时拟定一个固定拼写 | 与中文名属于同一命名体系，不冒充真实品牌 |
| 概念型号 | 版面需要时用中性字母与序号，如项目代号加01 | 不使用暗示未经验证性能的8K、Hi-Res、Pro Max等字样凑型号；明确为概念型号 |
| 主标语 | 提炼视觉气质、类别与使用情境 | 不写未经验证的性能承诺 |
| 外观短句 | 写圆角轮廓、孔阵、配色、可见控制布局等 | “织物观感”不能自动升级为“再生羊毛”；金属质感不能等同铝合金 |
| 功能说明 | 依据用户提供或确认的信息 | 可见接口不能自动证明快充或数据规格；孔阵不能证明声学性能 |
| 参数 | 仅用用户确认的准确参数 | 缺失时整体换为外观文案，不保留原数字或单位造成误读 |
| 页脚 | 有真实信息时采用；否则用克制的类别／系列词 | 不编网址、版权归属、认证、地址、二维码 |

## 文案流程

1. 汇总明确事实、可见特征和未知信息。类别不明时使用中性称呼；只有类别会实质改变命名或功能表述时集中澄清。
2. 选择一套名称；仅为本项目拟定，不承诺全球唯一或已注册。采用用户已有品牌时只补缺失产品名／型号，不另造母品牌。
3. 建立固定名称、英文大小写和型号字面值。主标语可准备中文与英文版本，使用哪种语言由对应参考版式及用户要求决定。
4. 逐参考写出实际要上版的文字，记录框位、层级、预计行数和长短版本。主标题若原为2词，新稿也优先保持相近视觉长度，不硬塞一整段中文说明。
5. 每个标题可围绕整体外观、细节、使用情境等变化，但不能用不同型号假装不同版本。无事实依据时不用“旗舰”“专业级”“极致音质”等性能暗示。
6. 文字较多时优先缩短文案，保留参考的层级、留白与节奏。关键产品名和型号绝不为适应版位而改拼写；改用文案表中预定的短称。
7. 把当前版本逐字文案传入每次生成／精排任务。回看输出逐字核对，发现错字或型号漂移就修复，不只核对提示词。

## 简短示例（只示范方法，禁止跨产品套用）

用户确认是一款桌面音箱，六视图显示圆角浅色壳体与细孔面板，但未给技术参数：可拟“隅声 / NOOK / NK-01（概念型号）”，配“为桌面留一处声音”。细节文案可用“圆角轮廓”“细孔面板”，不能填入“蓝牙6.0”“24小时续航”“铝合金机身”。

若另一个参考完全无字，则该张保持无字；若参考上有第三方品牌与12H，用同一项目名称和适合该版位的外观短句替换，不继承品牌与12H。若用户已提供品牌名称和型号，整个命名示例全部失效，沿用用户信息。
